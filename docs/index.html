Features

The whole app is one executable. These are the parts most people touch first.

A word processor for Markdown

Type in the rendered text itself. Caret, selection, undo and redo, table cell navigation and an outline pane: word processor mechanics, but the file stays plain Markdown. The raw source is one toggle away.

One executable, nothing to install

MarkDownIt is a single exe written in C++. No Electron shell, no .NET runtime, no bundled dependencies. Copy it somewhere and run it.

Tables and structure

Insert a table and edit it by cell: Tab moves between cells and adds a row at the end, rows and columns come and go as single undo steps, alignment sits on the ribbon, and pipes escape themselves.

Zoom that remembers

Zoom from 25% to 400%: Ctrl+wheel zooms around the pointer and Ctrl+0 returns to 100% in place. Your level is remembered, and the View tab offers four column widths.

Mark text

Highlight passages with Ctrl+Shift+H. Marks live outside your file, survive moves and renames, and never reach your exports.

Find and replace

Ctrl+F and Ctrl+H open a dock along the bottom edge, with Match case and Whole word options, results that wrap around, and a replace mode one click away.

Drag and drop

Drop a .md file on the window from Explorer to open it.

Associate .md files

One ribbon command, and double-clicking a Markdown file opens MarkDownIt.

Follows the file

When the file changes on disk, the view reloads on its own. F5 forces it.

Word wrap

Toggle wrapping off and long lines run past the edge instead of reflowing.

Editing

A word processor for Markdown files

Most Markdown tools put a preview next to your text. MarkDownIt puts the caret in the rendered text instead. It behaves like a word processor: you type formatted text directly, and the .md file on disk stays plain Markdown.

  • Caret, selection, undo and redo work on the rendered document.
  • Bold, italic, links, inline code, headings, lists and quotes are on the ribbon.
  • Tables get cell navigation with Tab, plus row and column commands.
  • Find and replace, an outline pane, and zoom from 25% to 400% are built in.

That is the WYSIWYG part: what you see is what the file renders. Prefer the raw text? Switch to the source view.

Diagrams

Mermaid, drawn natively

Mermaid blocks in your Markdown become diagrams in the window. They are parsed and drawn by the app itself, on the same Direct2D pipeline that renders the rest of the document.

  • Flowcharts with five node shapes, four directions and simple subgraphs, plus pie charts and sequence diagrams.
  • No browser window, no JavaScript engine, no network.
  • Layouts follow dagre's topology and are checked in CI against real mermaid.js output, matching within half a device-independent pixel.

Styling directives, click handlers and nested subgraphs are not implemented yet.

Questions

FAQ

Short answers to the questions that come up.

What is MarkDownIt?

A native Windows app for Markdown files. It opens .md files from Explorer, parses them with the built-in md4c parser, renders with Direct2D and DirectWrite, and lets you edit in a rendered view or a source view.

Is it a word processor?

That is the closest description. MarkDownIt gives you caret, selection, undo and redo, tables with cell navigation, outline and find and replace, all on the rendered document. The difference from Word: the file is plain Markdown, readable by any tool.

What does WYSIWYG mean here?

The rendered view is the editor. You place the caret in the formatted text and type. The .md file keeps its Markdown the whole time, and if you want the raw text you switch to the source view.

Which Windows versions does it run on?

Windows 10 or 11, x64. The rendering APIs it uses ship with Windows, so there is nothing else to install.

Does Mermaid rendering need the internet?

No. Mermaid blocks are parsed and drawn by the app itself, with no browser window, no JavaScript engine and no network calls. Flowcharts, pie charts and sequence diagrams are supported. Styling directives, click handlers and nested subgraphs are not implemented yet.

Can MarkDownIt read Word documents?

Yes. MarkDownIt imports .docx files and converts them to Markdown, and it reports what it could not carry. Word-specific elements such as tracked changes and comments stay in the original file.

Can it save Word and PDF files?

It exports .docx and PDF. The Word export is checked in CI by an independent reader, and the PDF export keeps layout, page breaks and footers.

Why is it a native app instead of Electron?

Because a Markdown window does not need a browser inside it. MarkDownIt is one executable that renders with Direct2D and DirectWrite, so it behaves like the rest of Windows, and there is no runtime to download.

Is MarkDownIt free?

Yes. MarkDownIt is MIT licensed and free for personal and commercial use. The source code is on GitHub.
